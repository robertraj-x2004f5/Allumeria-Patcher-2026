## 🎮 About the Game

Allumeria is a voxel sandbox adventure game developed and published by Infinimelon. It entered Early Access on August 28, 2026, combining exploration, crafting, building, dungeon crawling, boss battles, and RPG-style progression.

---

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Allumeria**. This trainer enhances Allumeria with optional gameplay assists for exploration, building, crafting, resource management, movement, and combat. It is designed for the Early Access version and lets players customize difficulty without changing the core voxel sandbox experience.

**Target Audience:** Players who want to explore Allumeria freely, test building ideas, experiment with weapons and abilities, reduce repetitive resource gathering, or make dungeon and boss progression more accessible.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Activate movement assistance before traveling through caves, dungeons, or difficult terrain. Enhanced sprinting, jumping, climbing, gliding, and flying can make exploration faster, but disabling the option before entering normal traversal sections helps preserve the intended challenge.

### Tools & Inventory

Use the inventory options to maintain crafting materials, duplicate selected items, or reduce crafting costs. Keep the trainer active while gathering and crafting, then disable it before saving if you want a more conventional progression record.

### World & Environment

Allumeria uses procedurally generated voxel environments with destructible terrain, multiple biomes, structures, resources, enemies, dungeons, and bosses. The trainer is useful for testing advanced building tools, shaping blocks, painting materials, and experimenting with lighting without spending large amounts of time gathering supplies.

### Combat & Weapons

Combat includes weapons such as swords, crossbows, bombs, shock arrows, boomerangs, shuriken launchers, and other unusual items. Enable health protection or combat assistance before entering dangerous areas, and use one-hit options carefully around bosses to avoid skipping progression unintentionally.
